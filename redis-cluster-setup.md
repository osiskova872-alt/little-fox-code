# 🚀 Развертывание кластера Redis из 9 узлов

**Выполнил:** Шишкова  
**Группа:** 22ГМУ-УЦП11.2  
**Задание:** КТ 2_3

---

## 📋 Требования
- 9 серверов (виртуальных машин или контейнеров)
- Redis 7.0+
- Открытые порты: 6379, 16379
- Сеть с доступом между всеми узлами

## 📁 Файлы конфигурации

### 1. Базовый конфиг Redis (`redis-base.conf`)
```conf
port 7001
cluster-enabled yes
cluster-config-file nodes.conf
cluster-node-timeout 5000
appendonly yes
daemonize no
bind 0.0.0.0
requirepass ваш_пароль
masterauth ваш_пароль
